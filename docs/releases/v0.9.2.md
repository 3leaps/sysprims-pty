# sysprims-pty v0.9.2

Dependency pin release: the crate now consumes the published sysprims **0.2.4**
line (`sysprims-session`, `sysprims-timeout`).

## Changes

- Moves the exact `sysprims-session` and `sysprims-timeout` pins from 0.2.3 to
  0.2.4.
- Refreshes locked `anyhow` and `event-listener` dependencies to versions
  without published advisories.
- Pins the contributor toolchain to Rust 1.88.0 so local gates match CI and
  fixes MSRV clippy findings in the async example.
- No API or behavior changes.

## Compatibility

- Upstream contract: sysprims `v0.2.4`, commit
  `5cb5047ab005bce17f376da3cb88d7afd6006877`.
- MSRV: Rust 1.88.0.

## Containment boundary

This crate continues to use the Rust `sysprims_timeout::ContainmentGuard`
timeout/session path. The managed contained-process handles added in sysprims
0.2.4 apply to the Go and TypeScript bindings, which this crate does not
consume. A successful `guaranteed` acquisition is not an OS-enforced
non-escape boundary; descendants can leave a cooperative process group.
